# weather-service

## Descrição
O **weather-service** é responsável por consumir a API pública **OpenWeatherMap** e padronizar os dados climáticos para o sistema. Ele fornece informações meteorológicas em tempo real e previsões futuras, que serão consumidas por outros microsserviços e pelo frontend.

## Tecnologias
- Node.js
- TypeScript

## Como rodar o projeto
```bash
npm install
npm run dev
